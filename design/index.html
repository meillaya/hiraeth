Hiraeth. — design system

One quiet sheet, measured to the pixel.

This document formalises Hiraeth: the canonical token set, the responsive type and grid rules, the component contracts, and the device matrix the implementation is held to. Every value below is read from the live token stylesheet, so this page cannot drift from the running site.

Principles

The interface is an edition, not a dashboard. Content sits on one paper sheet over a sage ground; hairlines replace boxes; serif display type carries hierarchy and Archivo carries interface text. Nothing floats, nothing glows, and nothing crowds the page.

01 · Sheet

One reading surface

The page is a single rounded sheet on the sage ground. Content never escapes the sheet; the only full-bleed element is the sage field behind it.

02 · Type

Serif voice, sans tools

Newsreader sets titles, decks, and long-form prose. Archivo sets labels, controls, captions, and numbers. No third voice is introduced.

03 · Measure

Print rhythm

Rules are 1px, radii are generous, and the page gutter is the only horizontal constant. Spacing steps in 2px increments at small sizes and 4px above 16px.

Token set

Canonical file: assets/css/tokens.css. Names are stable API: components consume them by name, never by raw value. The tables are generated from the live stylesheet at load.

Book-page more-from tray

    

      The foot of every record closes with a tray of the same press's other
      volumes. It is a bounded reading suggestion, not a second catalogue: at
      most four records, never the record being viewed, and a single link to the
      press dossier for the complete list. When the press has no other public
      record the tray is omitted rather than filled with unrelated titles.

Local shelf

    

      The shelf is a browser-local reading list: no account, no server write,
      and no third-party storage. It is available from the header on every
      public page, from a Save to shelf control on each record, and from
      the /shelf page. The list stores the metadata shown at the
      moment of saving, so it can render without a catalogue request.
    


    

      

        
01 · Capture

        
One record, one toggle

        
The record action is a toggle button. The pressed state is both visible (“Saved”) and announced.

      

      

        
02 · Review

        
Dialog and page

        
The header opens a compact dialog; the shelf page carries the numbered reading list, remove actions, and plain-text export.

      

      

        
03 · Privacy

        
This browser only

        
Nothing is uploaded. The control copy always says “Saved in this browser.”

      

    


    
Storage contract

    

      
FieldTypeRule

      
        
slugstringRequired. Public book slug, ≤180 characters; the deduplication key.

        
titlestringRequired. Plain text, ≤300 characters; rendered as text, never HTML.

        
authorstringOptional display names, ≤300 characters.

        
publisherstringOptional press name, ≤300 characters.

        
publisherSlugstringOptional; only used to build a same-origin press link.

        
yearstringOptional; four digits, or empty.

        
coverstringOptional. Same-origin path under /covers/cache/ only; anything else becomes a typographic fallback.

        
formatsstring[]Optional; at most six labels of ≤40 characters.

        
isbnstringOptional; ≤40 characters, exported only.

        
savedAtISO stringOptional client timestamp; never used for ordering.

      
    

    

      Canonical key: hiraeth-shelf-v1. Value: a JSON array in
      newest-saved-first order, capped at 200 records. A corrupt value, a
      missing or malformed slug, or an unsafe cover URL is discarded on read;
      the page must still render. If localStorage is unavailable,
      the shelf stays in memory for the page session and the UI reports no
      failure.

Behaviour and failure

    

      
EventRequired result

      
        
Save pressedRecord is prepended, persisted, the button reads “Saved” with aria-pressed="true", and the count updates.

        
Saved pressed againRecord is removed, persisted, and the button returns to “Save to shelf”.

        
Header Shelf openedThe dialog renders the current list and calls showModal(); focus moves into the dialog.

        
Close, Escape, or backdropThe dialog closes; focus returns to the opener; body scrolling is restored.

        
Remove in dialog or pageThe row disappears immediately and the count updates; the shelf remains open.

        
ExportA plain-text reading list downloads. Nothing is sent to the server.

        
Another tab writesThe storage event re-renders the count, dialog, and page.

        
Corrupt or unavailable storageInvalid records are ignored; unavailable storage falls back to session memory. No console-breaking error or blank page.

        
JavaScript disabledThe dialog is inert and the shelf page keeps its server-rendered empty state and starter shelf.

      
    


    
Accessibility

    

      

        
    
          
  • 01Toggle. The save control is a real <button type="button"> with aria-pressed; its accessible name includes the book title and starts with the visible “Save to shelf” / “Saved” text, so it satisfies label-in-name.
    • 
          
  • 02Dialog. Native <dialog> with aria-labelledby, a visible Close control, Escape support, and focus return.
    • 
          
  • 03Announcements. A polite live region reports save and remove actions; the header count is not a live region on load.
    • 
          
  • 04Targets. Save, Close, Remove, header, menu, and footer controls are at least --sb-target-min (44px) tall on touch bands.
    • 
        

      

      

        
    
          
  • 01Headings. Shelf page: h1 “Shelf”, h2 “Reading list”, h3 per row. Empty state: h2 “A shelf waiting to be filled.”
    • 
          
  • 02Images. Saved covers use “Cover for {title}” alt text; missing covers render the labelled typographic fallback.
    • 
          
  • 03No invented data. The shelf stores only what the record displayed; it never fills missing authors, dates, or covers.
    • 
          
  • 04Motion. Reduced motion removes transition and smooth scroll; no layout animation is introduced.
    • 
        

      

    


    
Verification

    
    
      
  • Save two records, reload, and confirm the header count, dialog, and shelf page agree in newest-first order.
    • 
      
  • Remove a record from the dialog and from the shelf page; both persist and update the count.
    • 
      
  • Open the shelf with the keyboard, press Escape, and confirm focus returns to the Shelf control.
    • 
      
  • Inject corrupt JSON, an unknown slug, and an external cover URL; the page renders without script errors and drops the invalid values.
    • 
      
  • Export the shelf and confirm the file lists title, author, press, year, ISBN when present, and the absolute book URL.
    • 
      
  • Assert the more-from tray is bounded at four records, excludes the current record, and only contains the same press.
    • 
      
  • Capture /shelf and a book at 320, 390, 760, 1040, and 1440 px; assert no horizontal overflow and 44px targets on touch bands.
    • 
    

  


  

    
Interaction and accessibility

    

      

        
    
          
  • 01Focus. 2px solid --sb-green, offset 3px, on every interactive element. No focus styles are removed.
    • 
          
  • 02Hover. Colour and 1px border changes only; no lift, scale, or shadow. Transition 140ms ease.
    • 
          
  • 03Motion. prefers-reduced-motion removes smooth scroll and transitions.
    • 
          
  • 04Contrast. Ink on paper ≥ 15:1; muted on paper ≥ 5.4:1; green-ink on green ≥ 7:1.
    • 
          
  • 05Targets. Minimum 30px tall for page controls; header tools, menu rows, shelf controls, and footer links use --sb-target-min (44px) at ≤1040px.
    • 
          
  • 06Disclosure. The Menu panel is anchored to the header, not the viewport. Rows are 44px; Escape and any link click close it; the footer navigation stays visible below 900px.
    • 
          
  • 07Captions. Hero and press captions wrap the title; the author is never clipped or ellipsised. Title and author align to the cover's left edge.
    • 
          
  • 08Micro-type. Functional labels never fall below --sb-text-micro (10px); secondary labels set 10–11px with tracking reduced to compensate. Only decorative fallback text inside tiny cover thumbnails is exempt.
    • 
        

      

      

        
    
          
  • 01Images. Covers carry descriptive alt text; fallbacks are labelled “Typographic cover fallback; no cover asset is available.”
    • 
          
  • 02Structure. One h1 per page; shelf trays use h2; cards use h4 under their section heading.
    • 
          
  • 03Labels. Every select and input has a visible label; decorative rules are aria-hidden.
    • 
          
  • 04Live regions. Result counts and the flash group are polite live regions.
    • 
          
  • 05No remote assets. Fonts and covers are same-origin; the CSP stays default-src 'self'.
